以后一切类似推荐都拆为五个独立判定：①单家公众查询；②是否取得可解析原件；③拟定频率的自动获取依据；④拟定公开展示／转载／再分发依据；⑤稳定原始 ID 和更新线索。每项写原件链接、访问日、真实动作和未知项，不把“页面有下载按钮”“有 API 文档”“robots 未禁止”互相替代。

本轮先选**领域＋城市／数据集**验证链路，不预设“山东全省有完整数据”。济宁目录属于可继续核验的具体候选；试点地应在实取样本、字段深度、更新路径和使用条件检查后确定。正式目录的分母应分别报文件、原始行、来源内 ID、待核机构及已确认机构，未知地区保持未知。
