# 跨行业信源平台调研与试点模板

本模板用于从一个行业的真实来源出发，设计可追溯、可更新的查询产品。复制后按行业填写，不把示例口径当成事实。研究、有限探测、采集、公开发布是四个独立决策；上一阶段完成不自动授权下一阶段。

## 0. 填写纪律与状态

- 每项事实写明准确 URL、页面／附件位置、发布单位、发布日期或“未标注”、访问时间及验证动作。搜索摘要只能记为线索，不算已核验原件。
- 未知值留空或记为 null；不得填 0、推测有效状态或编造更新时间。数值 0 仅用于已检查且确认为零的计数。
- 区分“原件刊载”“来源声称”“人工确认”和“当前仍有效”。历史名单不能直接证明当前状态。
- 一份文件、一个页面、一条原始行、一个来源 ID、一个凭证号、一个已确认对象分别计数；不得互称。
- 研究状态：未调查 → 已找到（有线索）→ 已核验（打开原件并定位样本）。遇到登录、验证码、403、429、附件失效或条款限制记“受阻”，保留证据并停止该来源探测。“已检索未发现”保留检索范围和日期；“无适用来源”仅在适用范围确实排除该类别且有依据时使用。
- 状态属于“地区×类别×来源”，不等于地区全量覆盖。一个来源已核验，不自动升级上级、下级或同类其他地区。

## 1. 需求输入卡

| 项目 | 待填写内容 |
| --- | --- |
| 行业、目标用户与核心任务 | 谁要做什么决定；查询对象和完成标准是什么？ |
| 产品主张 | 哪些字段可展示；每字段想证明什么，不能证明什么？ |
| 对象与排除项 | 分别列出经营主体、服务对象、场所、资格、项目、品牌等适用概念；明确非目标对象。 |
| 地域与版本 | 行政／监管范围、权威区划来源及版本截止日；特殊地区如何表示？ |
| 类别与主管方 | 按真实监管职责定义类别，不以搜索关键词代替法定分类。 |
| 时效要求 | 查询时可接受的来源陈旧度、复核频率、过期提示。 |
| 数据与权限 | 是否涉及个人信息、商业授权、原件转载、公开缓存、用户更正？ |
| 试点边界 | 地区、类别、来源数、最大网络请求和人工作业预算。 |
| 成功与停止标准 | 最小可用字段、抽取率、复核量、发布闸门和遇阻停止条件。 |
| 负责人及日期 | 产品、数据、合规、工程责任人；建卡和复核日期。 |

## 2. 对象、关系与可主张事实

先定义行业对象，再选择数据库表。登记／注册存在、业务许可、某地场所、品牌归属、产品或服务，是不同主张；没有证据时不得按名称合并。

| 对象代码／名称 | 定义与最小身份字段 | 与其他对象的关系及有效时间 | 不得与什么混淆 | 权威来源与待核问题 |
| --- | --- | --- | --- | --- |
| 待填 | 待填 | 一对多／多对多／历史更名；待填 | 待填 | 待填 |

| 主张 ID | 适用对象与字段 | 原件能证明什么 | 原件不能证明什么 | 时间口径 | 冲突处理与复核人 |
| --- | --- | --- | --- | --- | --- |
| 待填 | 待填 | 待填 | 待填 | 发布／截至／生效／采集；待填 | 待填 |

关系单独建“待核关联”：左、右对象 ID，关系类型，候选理由，反证，支持原件，起止时间，决策状态，复核人和复核时间。自动匹配只能创建候选；名称一致本身不足以确认同一性。名称变更保留旧称证据和适用时间，不覆盖历史观察。

## 3. 地区 × 类别调查任务矩阵

先从权威资料取得地区代码、名称、层级、上级代码、行政类型与版本截止日；另记适用司法辖区、历史别名及代码生效起止日。第三方区划库仅作候选，必须抽检官方版本、层级、特殊地区、重复代码和许可范围；没有可靠代码文件时，矩阵仅为待建立的结构，不得宣称全国已实例化。直辖／直管及无中间层级的地区按真实层级建模，不造虚拟区县。业务记录的地区归属可以未知或跨地区，不强行填充。

| 地区代码 | 地区名称／层级／上级代码 | 区划版本及 URL | 行业类别 | 调查状态 | 已核验来源 ID | 覆盖判断及分母 | 最后调查日／证据 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 待填 | 待填 | 待填 | 待填 | 未调查 | null | 未知 | null |

覆盖判断单设“未知／局部可证／来源声称全域／经复核全域”，并写明所依据的地域与时间。上级名单即使列出下辖地区，也只证明该原件刊载的行；不能推断每个下级单位都有完整数据。

## 4. 逐来源证据与四问五项可行性

每份页面或附件填一条，动态分页与不同年度版本分别保存。准确原件 URL 与公告页 URL 分列，防止只留搜索结果。

| 字段 | 待填写内容 |
| --- | --- |
| 来源 ID、标题、原件 URL、公告页 URL | 待填；记录最终重定向 URL。 |
| 发布／运营单位、主管关系 | 页面原文与核验位置；不从域名猜测。 |
| 适用地区代码／层级、行业类别 | 原件实际覆盖范围；不得向下传播。 |
| 发布日、名单截至日、生效日、访问日 | 分开记录；未标注写 null。 |
| 格式、页数／工作表、可见原始行数 | HTML、CSV、XLS/XLSX、文字 PDF、扫描件等；行数只称行数。 |
| 逐行原始字段与样本定位 | 表格名称、页码、行号或稳定锚点；保留空值及未知列。 |
| 更新线索 | 定期表、增量公告、版本号、历史链接或未知。 |
| 登录／验证码／HTTP 状态／重定向 | 真实观测、访问时间、Retry-After；遇禁止或限流停止。 |
| robots.txt 与网站条款 | 准确 URL、可见条款、访问日期；条款未明即“未核实”。 |
| 获取与再利用边界 | 技术上可取、拟定频率自动获取、缓存／改编／转载、个人信息分别判断；各留条款位置。 |
| 解析难度与质量风险 | 表头变化、跨页、扫描 OCR、缺字段、重复观察。 |

按四个问题记录，其中第 3 问拆成自动获取与再利用两个独立裁决。每格填“是／否／受阻／证据不足”，附依据和下一步：

| 判断 | 结论／证据 URL 与位置／下一步 |
| --- | --- |
| 公众能否查询单个对象？ | 待填 |
| 是否有可解析的公开原件？ | 待填 |
| 按拟定频率自动获取是否有依据？ | 待填；公开查询、robots 未禁止不等于自动获取许可。 |
| 拟定展示／转载／再分发是否有依据？ | 待填；可下载不等于可以公开原件或个人信息。 |
| 是否有稳定原始 ID、发布时间与更新线索？ | 待填 |

试点分类：可作为第一批试点／仅能人工查询／需授权／技术受阻／证据不足。分类只针对已列证据和拟定用途，不作全站永久判断。

字段优先级按“主张×对象×时间”制定；新公告、旧名单、登记库和主体自报的证明范围不同。冲突时并列保留原始观察，标记待复核，不自动选最新或最常出现的值。人工队列至少包含同名异体、名称变更、多场所、重复凭证、停办／撤销、不同来源冲突及解析异常；每条处理留决定、理由、证据和操作者。

## 7. 公开投影审批

私有原件、清洗候选、可公开投影分层存放。进入公开投影前逐来源、逐字段审批；未批准、待核或个人联系方式默认不发布。自报信息须单列，不显示为官方事实。

| 来源／字段 | 可转载或展示的条款依据 | 自动获取依据与频率 | 个人信息判断 | 字段语义及日期检查 | 质量抽检 | 审批人／时间／状态 |
| --- | --- | --- | --- | --- | --- | --- |
| 待填 | URL、条款位置、访问日期 | 待填 | 待填 | 待填 | 待填 | 待审 |

审批状态为待审／批准／拒绝／撤回。批准须关联具体用途和版本；条款、来源或字段用途变化后重新审查。公开页面显示来源、适用对象、发布日期或截至日、核验状态及原文入口；无法证明的状态不展示为当前事实。

## 8. 试点验收与统计分母

| 指标 | 分母与定义 | 实测值 | 证据／验收阈值 |
| --- | --- | --- | --- |
| 原件数与完整率 | 请求成功取得的不可变原件；有哈希、URL、时间的比例 | 未知 | 待填 |
| 原始行数与抽取率 | 可见原始行数作分母；保留解析失败与空页 | 未知 | 待填 |
| 不同来源 ID 数 | 每个来源内部去重，跨来源不合并 | 未知 | 待填 |
| 不同凭证号数（若适用） | 非空原始号去重；不等于对象数或有效数 | 未知 | 待填 |
| 候选对象数 | 清洗及待核匹配产生的候选 | 未知 | 待填 |
| 已确认对象数 | 达到行业证据标准、留有复核决定的对象 | 未知 | 待填 |
| 详情字段覆盖率 | 已确认对象作分母，逐字段报告非空且可追溯比例 | 未知 | 待填 |
| 地区×类别覆盖 | 按权威区划版本列已核、局部、未知和受阻单元 | 未知 | 待填 |
| 公开审批通过率 | 实际拟发布的来源与字段作分母，依据逐项可查 | 未知 | 公开字段须全部获批 |
| 更新与恢复 | 变更发现、失败重试、断点收据、旧值留痕实测 | 未知 | 待填 |

试点报告另记总人时、外部费用、每个已确认对象的成本、最后更新日和仍未知的地区／类别。上线标准只能由已验证的来源、对象、字段和授权构成；页面数、抓取成功率或候选行数不能替代可用目录的验收。
