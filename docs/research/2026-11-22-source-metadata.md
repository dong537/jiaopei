# 来源元数据归档：robots / 条款 / 四个独立结论（2026-11-22）

> 本文件为 `sources.mjs` 17 个来源 + `collector/` 4 个来源补齐**来源元数据**。
> robots.txt 结论来自 2026-11-22 的**有限只读探测**（每域名 1 次请求，共 16 次，见 `data/whitelist/robots-probe.json`）。
> 条款结论区分「已核验」（有研究文档/实际打开的条款依据）与「未核验」（如实标注，不以搜索摘要推定）。

## 0. 探测方法与边界

- **robots.txt**：2026-11-22 逐一请求 `https://<host>/robots.txt`，记录真实 HTTP 状态与内容。
  结果：16 个域名中 15 个返回 404（未声明）；`innovation.jinan.gov.cn` 返回 200 但内容为 HTML 软 404 页（非真实 robots），`www.gdsx.gov.cn` 超时未响应。
  **结论：16 个来源域名均无有效的 robots.txt 声明。** 这「不禁止」也不「允许」批量抓取，属中性结论——不能据此声称允许批量采集。
- **条款**：政府门户的「网站声明/版权声明/隐私声明」不等于数据再利用许可。凡未打开核对原文的，一律标「未核验」。

## 1. 四个独立结论的判定口径（所有来源通用）

对每个来源，四个结论**互不混同**，且都只在有证据时判「是」：

1. **公众能否查询单家机构**：能 / 不能 / 需登录 / 仅列表 —— 依据「是否有人工核验的查询入口」。
2. **是否有可解析公开原件**：有(html/xlsx/xls/pdf文字层) / 扫描件 / 无 —— 依据「是否已下载并解析出可定位行」。
3. **是否允许按拟定频率自动获取及再利用**：允许 / 禁止 / **未声明** / 需授权 —— 无明确授权条款时一律「未声明」。
4. **是否具备稳定原始行 ID、发布日期、更新线索**：有 / 无 / 部分。

## 3. 关键结论

1. **robots 层面**：16 个来源域名均无有效 robots.txt，属「未声明」。这不构成「允许批量抓取」的依据，仅说明**没有机器可读的禁止规则**。
2. **条款层面**：除龙岩/济南/福州/新洲在 `collector` 研究文档中有「未见明确禁抓、也未见再利用许可」的初步记录外，**whitelist 17 个来源的网站条款均未逐条核验**，一律标「未声明/未核验」。
3. **四个结论的落地含义**：
   - ①②（可查询、有原件）大多成立，支撑「人工核验 + 小样本采集」；
   - ③（自动获取/再利用）**全部为「未声明」**，因此**持续定时采集与公开转载均不能启动**，只能维持「一次性低频内部研究样本」；
   - ④（稳定行 ID/日期/更新线索）仅龙岩、济南「有」稳定行 ID，其余「部分」。
4. **后续**：要升级为持续采集或公开再利用，必须逐来源打开「网站声明/版权声明/隐私声明」页核对原文，取得明确授权或改为开放数据/授权渠道；在取得前，第 3 章「未声明」结论就是硬约束。
