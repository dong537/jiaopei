# 全国教培机构信源平台：独立审计与有限采集设计

核验日期：2026-11-24（中国标准时间）。范围：中国大陆全国。**本轮只读检查项目和有限探测公开来源；没有运行全国采集、修改原件、现有任务或公开页面。** 全国逐地级、逐县区来源调查尚未完成；未调查不填 0，也不声称全国覆盖。

## 1. 执行结论与计数口径

- 目前能支持**内部小样本字段映射**的原件：龙岩 A 类 XLSX、济南高新区 A 类 HTML、福州 C 类 XLSX。三者均没有在本轮取得持续自动获取及商用再利用的明确许可，不能直接形成正式公开目录。武汉新洲只核了表头，仍是候选；继续教育全国查询站 robots 禁止自动访问。
- 广东现有 27 来源、2,943 名单行、2,909 个不同许可证号、13 个地市，是项目私有快照的不同分母；2,871 条预览记录也不是独立机构数。企查查广东库 163,776 条主体候选，Python 私库 43 个文件、306,383 行原始观察，均不是已确认教培机构数。本轮离线重算广东 27/27 份原件和预览的 SHA-256 均匹配，只证明私有原件完整。正式发布文件 data/gd-public-release.json 不存在。
- 来源调查、采集可行性、字段事实、公开授权是四个相互独立的关口。当前没有全国可发布的机构数量或覆盖率。推荐先做跨类别的**内部证据样本试点**；商业公开试点须等逐源权利与质量审核。

计数必须分栏保存：请求数 / 原件文件数 / 名单可见行数 / 解析成功行数 / 不同原始行 ID 数 / 不同许可证号数 / 候选机构数 / 人工确认机构数 / 校区数。一个来源覆盖一个市的若干区，不代表该市所有县区覆盖；省级公告也不自动覆盖下级。

## 2. 对象、关系和字段边界

| 对象 | 主键及最低字段 | 不可混淆的含义 |
|---|---|---|
| Brand 品牌 | 内部 ID、原名、别名、使用时间段 | 市场称谓；不是法律主体或许可证持有人。 |
| LegalEntity 登记主体 | 内部 ID、统一社会信用代码（可空）、主体类型、登记名称、登记机关、登记状态及时间 | 工商、民政或事业单位登记；经营范围含“教育咨询”不证明获得培训许可。 |
| Institution 获准培训机构 | 内部 ID、原文机构名、类别、辖区、准入证据与核验状态 | 仅在主管部门许可／准入证据足够时确认的业务对象；无证号名单先留 OfficialListRow，不自动创建“持证机构”。学历学校不能因名称含“学校”自动纳入；职业培训学校须按实际监管类别判断。 |
| Campus 校区／教学点 | 内部 ID、原名、地址、行政代码、适用时间、机构关联状态 | 场所对象；一个机构可多点，名单行不必然等于校区。 |
| License 许可／核准 | 内部 ID、原始编号（可空）、证件类型、发证机关、许可范围、起止日期、观察日期、状态证据 | 编号刊载只证明原文有此号；历史白名单或年检不证明今天有效。驾培备案不能写成办学许可证。 |
| Course 课程 | 内部 ID、原文课程名、开设机构／场所、价格与日期（可空） | 许可范围不是实际课程；没有来源的课程和价格保持 null。 |
| OfficialListRow 官方名单行 | 来源 ID＋原件版本＋表／页／行定位、原始单元格、名单类别、备注 | 一次发布的一条观察；黑、灰、白名单分别标记，不自动升格为许可或机构。 |
| Source 来源定义 | 来源 ID、发布机关、站点、辖区、监管类别、访问与使用政策版本 | 描述一个发布渠道或具体数据集，不等于下载的字节。 |
| SourceRecord 来源原件 | 原件 ID、来源 ID、原 URL／最终 URL、请求时间 UTC、HTTP/业务状态、重定向、Retry-After、字节 SHA-256、文件路径、发布日期／截至日、批次 | 一次不可覆盖的网页响应或文件获取；失败响应也留存。 |
| FieldEvidence 字段证据 | 证据 ID、对象类型／ID、字段、原始值、原件 ID＋行定位、发布日期／截至日／采集时间、核验状态、复核人、前版本 | 事实以逐字段证据支持，冲突与旧值不覆盖。 |

关系：Brand 与 LegalEntity、Institution 经**带有效期和证据的关联表**可多对多；LegalEntity 与 Institution、Institution 与 Campus 通常一对多，但只在证据足够时确认；一个许可可关联多教学点，一处教学点可有历史换证。高校学历继续教育教学点另以高校—设点单位—教学点关系建模，不强塞进中小学生校外培训机构表。名称变化建立 Alias/NameHistory 和旧值证据，原始行永不改写。同名、同号、近似地址只能生成候选关联；确认需至少强标识加来源一致性或人工复核留痕。

类别层：A 教育部门中小学生校外培训，B 体育／文化／科技部门对应的非学科校外培训（可与 A 同业务类，但来源与审批机关不同），C 人社职业技能培训，D 高等学历继续教育校外教学点，另设驾培独立类；E 工商／民政／商业目录仅补充登记主体或检索线索，不升级为 A—D 的许可证明。学校与培训机构不得按名称混合。

## 6. 来源专属适配器、证据优先级和数据流

~~~mermaid
flowchart LR
  G[权威行政区划版本] --> T[地区×类别任务]
  P[来源权利与访问复核] --> N[同站锁／硬预算／请求账本]
  T --> P
  N --> R[私有不可覆盖原件 SourceRecord]
  R --> A[来源专属解析器]
  A --> O[官方名单行／字段证据]
  O --> C[机构、主体、校区候选关联]
  C --> H[人工复核及冲突队列]
  H --> Q[授权／隐私／语义／日期质检]
  Q --> D[可回滚公开投影]
  D --> W[网站查询]
~~~

**数据与模块边界**：行政代码版本是地区主键的权威源；原件及请求账本是采集事实源；派生表可重建。source adapter 只理解某个公告的 HTML 表、工作表或 PDF 版式，输出原行、未知列、null、重复观察和异常。公共能力仅负责有真实重复的锁、预算、请求账本、不可覆盖存储、哈希和收据；实体匹配与公开决策不在抓取器内。现有 Python collector 是有限复用起点，不把原来的龙岩／济南参数推广成全国参数。

**适配器优先序**：龙岩 XLSX、济南 HTML、福州 XLSX 可作内测试点；武汉新洲需先核白灰黑实际数据行；广东茂名需复核原件及逐源使用条件；B 类[郑州公告](https://public.zhengzhou.gov.cn/D280808X/10121884.jhtml)／[南京公告](https://wlj.nanjing.gov.cn/njswhgdxwcbj/202607/t20260703_5871181.html)、D 类省级教学点公告只列下一批候选，不在本轮写适配器。扫描 PDF 先识别为 scan、量化 OCR 行抽取与关键字段错误，再人工审查；不能算作结构化完整覆盖。

**逐字段来源优先级**并非单一“官方 > 商业”排序：登记名称和信用代码以相应登记机关当前公开记录为准；许可类型、证号、有效期和停办以发证／监管机关的证件或处分原文为准；名单在册状态仅以该名单的发布时点为准；校区地址优先场所许可或主管部门当前名录；实际课程优先有日期的机构一方原文并标“机构自报”，不得把许可范围直接写成课程；商业目录仅用于发现和补充线索。来源较新不自动压倒权威等级较高但适用对象不同的证据；冲突进人工队列，旧值及其原件保留。

**一次有限请求**必须先核来源规则并声明 max-pages、max-ids、max-requests 和站点保守间隔；列表、详情、robots／探测共享同一 host 账本和进程锁。请求发出前占预算，记录开始／结束 UTC、状态、业务码、重定向、耗时、Retry-After、响应身份和预算消耗；403、429、验证码、登录跳转、身份不符或未知业务错误停该站批次，429 尊重 Retry-After。仅超时及明确暂时性 502/503/504 在硬预算内有限重试。失败响应、异常事件、blocked 状态和原件仍保留；恢复先离线校验原件＋sidecar＋哈希＋逐行收据，只有完整记录可跳过，损坏不自动重抓。

**格式验收**：HTML 保留表格和链接定位；XLS/XLSX 保留工作表、坐标、隐藏列与原值；CSV 保留编码、分隔符和原始字节；文字 PDF 保留页号／文本框；扫描 PDF 留影像与 OCR 置信度、裁切坐标。结构化原件的可见非空行数、解析行数、拒收行数须可复算并解释每个差额；扫描件逐条人工复核关键字段前不进公开投影。解析率只用“成功解释的适用原始行／人工确认的适用原始行”计算，不能以下载页数为分母。

**人工复核队列**：同名异主体、名称更改、证号重复或异名、一个主体多机构、一证多点、跨区号异常、停办与新旧来源冲突分别记录候选关联 ID、双方证据、冲突类型、复核结论、人和时间。未匹配只写“未找到关联证据”，不写“无证”；历史名录只写“截至该日曾刊载”，不写“当前有效”。确认关联须可回退，改判不删除原候选。

**三层隔离**：私有 raw/ledger/receipts → 私有清洗候选与复核结果 → 经过逐源授权、字段隐私、语义和时效检查的最小公开投影。原件和候选默认不可公开；校长、联系人、手机号、邮箱等另判必要性和可展示性。正式站点若采用现有 Cloudflare Edge 生产约束，发布构建只读取获批静态投影或 Edge 兼容存储，不依赖生产本地 SQLite。投影以批次版本与收据回滚；公告撤回则暂停相关展示并留内部历史。

## 8. 分省统一填表模板与证据标准

每个行政节点×A—E 一条任务：official_code、name、level、type、parent_code、code_version、category、status（未调查／已找到／已核验／受阻／无适用来源）、search_queries、search_date、searched_domains、coverage_assessment（未知／局部／核验范围及理由）、reviewer。状态与覆盖分列；“已核验”仅表示至少一个具体来源的所有必填证据齐全，不能表示该地区全量。

每个具体来源一条，不用搜索结果摘要代填：source_id、行政代码及层级、A—E 与细分、标题、**准确原件 URL** 和公告 URL、发布机关原文、发布日期、截至日、格式、逐家原始字段、样本行坐标及原文值、可见行数及计算法、HTTP 状态／最终 URL／重定向／Retry-After、登录／验证码、robots URL／状态／适用规则、站点条款 URL／原句／审核日期、单家查询、公开可解析原件、拟定频率自动获取许可、商业再利用许可、稳定原始 ID／日期／更新线索、解析难度、预算／实际请求数、SHA-256、核验者、访问时间、下一步。robots 未声明、版权页缺失、网页可查询均不能推定抓取或转载许可；访问异常保留真实状态并停止该来源。

证据等级：L0 搜索线索；L1 打开公告并确认标题／机关／日期；L2 打开原件并确认 HTTP、格式、哈希、至少一条逐家字段和定位；L3 核站点规则、条款、更新路径与使用授权；L4 来源行和字段经人工复核，且能进入公开投影。当前龙岩、济南、福州仅达到部分 L2/L3 项，不能因为原件 HTTP 200 就自称 L4。每条结论保留 URL、页码／表格坐标、2026-11-24 或实际访问日；无法打开与旧本地收据须分别标记。
