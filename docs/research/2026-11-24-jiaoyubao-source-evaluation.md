# 教育宝作为广东教培信源的核查

核验日：2026-11-24。用途：评估是否能为面向客户的广东教培目录补充机构、校区和课程线索。范围仅限本轮实际打开的公开页面、法律声明及 robots；未抓取机构列表、未取得数据接口、未联系网站，也未将其资料写入广东公开投影。

## 样本和证据

| 项目 | 本轮可复核的页面与观察 | 不能由此推断 |
| --- | --- | --- |
| 地区目录 | [广州教育宝目录](https://gz.jiaoyubao.cn/all/) 可浏览商家／机构卡片及类别、课程等入口。 | 目录内每个对象均为获许可培训机构、广州全量或当前在营。 |
| 单家样本 | [海米画室介绍页](https://gz.jiaoyubao.cn/edu/gzshms/about.html)展示店铺介绍、课程／校区／师资／评价等商业资料入口和页面更新时间；[校区联系页](https://gz.jiaoyubao.cn/edu/gzshms/lianxi.html)展示校区位置。此处只是网页样本，不将页面计数当成核验机构或校区数。 | 页面列出的品牌、企业名称、每个校区与同一许可证的关系；许可证现时有效性；课程实际开售。样本页未提供足够的主管机关原件和逐字段核验链。 |
| 来源性质及再利用 | [官网法律声明](https://www.jiaoyubao.cn/guanyu/falv/)称企业信息由相关企业自行提供，内容仅供参考，以企业官方信息为准；知识产权条款要求未经平台书面同意不得复制、传播、修改、发行、出售或以其他方式使用平台内容。 | 企业自行提供的信息已由主管部门核验；公开网页可直接复制进本项目商用目录。 |
| 访问规则 | 本轮单次 GET [广州子域 robots.txt](https://gz.jiaoyubao.cn/robots.txt) 得 HTTP 200；User-agent: * 下含 Disallow: /*?*、/s/、/orglist/、/org/ 等。[主站 robots.txt](https://www.jiaoyubao.cn/robots.txt)和[移动站 robots.txt](https://m.jiaoyubao.cn/robots.txt)也各有路径限制。 | 一个域名的 robots 规则适用于其他子域；未被 Disallow 的路径就获准商用采集或再利用。 |

## 五项独立结论

| 判断 | 当前结论 | 证据缺口／下一步 |
| --- | --- | --- |
| 公众可否查询单家？ | **是，已打开一页广州机构样本。** | 只证明样本可浏览，未测全站覆盖、登录条件变化。 |
| 是否有可解析公开原件？ | **有 HTML 页面样本。** | 未取得官方批量文件；页面字段随商家自报、版式和时间变化，尚未实测稳定解析。 |
| 拟定频率自动获取是否可行且获准？ | **未获证据，现不启动批量采集。** | 广州子域部分路径被 robots 限制；网站法律声明另对内容使用设限。技术能打开某页不等于自动采集可行或获准。 |
| 面向客户转载／再分发是否有依据？ | **未经书面同意不得把平台内容复制进本项目商业目录。** | 若要使用其字段、图片、评价或校区表，先走[官网联系渠道](https://www.jiaoyubao.cn/guanyu/lianxi/)询问具体授权、费用、更新、撤回和个人信息范围；本轮未联系。 |
| 是否有稳定记录 ID 和更新路径？ | **待核。** | 样本 URL 有路径标识、页面有更新时间；未核原始行 ID、变更日志、开放 API、批量下载或 SLA。不能把网页 slug 当作受保证的永久 ID。 |

## 对广东产品的决策

将教育宝登记为“**商业目录线索／批量及商用再利用需授权**”，优先用来发现可能漏查的机构名称或地区，而不是办学许可、当前合规或主体／校区关联的权威来源。内部研究可保存待核线索的链接和检索动作，再从主管部门公告、登记记录及机构自身材料独立核验；未经许可不复制教育宝的详情、课程、图片、评价或联系方式到公开页面。若签订数据合作，再按字段、用途、频率、个人信息、版本与撤回条件新增独立来源适配器和发布审批；不能把站点目录直接混入现有官方白名单投影。

与[广东页面竞品对照](2026-11-24-gd-competitor-seo-audit.md)的分工：该文只借鉴页面任务和导航，本文件判断其数据能否作为信源。二者都不证明教育宝上的商家为已许可机构。
