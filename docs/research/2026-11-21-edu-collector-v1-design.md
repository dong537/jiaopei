继续教育教学点另属高校学历继续教育体系，V1 不采。公告名单只能证明对应发布时点和辖区的名单收录，不能推导今日有效许可、登记主体或课程在售。对龙岩的内部研究采样不等于得到生产定时任务或公开目录授权。若正式执行时遇登录、验证码、403、429、身份不符或条款禁止，保存可获得的失败原件与事件并阻断，不更换代理或伪装身份。

## 目标、范围和成功标准

V1 服务数据研究员：通过 CLI 获取一个地方官方 XLSX，保留每次请求及原件，离线核验后输出最多若干条带逐字段证据的私有候选。成功标准是请求数、原始行数、不同来源行 ID、详情完整数、失败/待续数分别可复算，任何失败都不能被标作完整。V1 不做全国全量、工商主体自动归并、网页公开投影、课程价格、报名或机构自报采集。

## Source of Truth、对象和接口

- 不可变原始响应是采集事实源：以一次请求的 attempt ID 保存原始字节、URL、UTC 时间、HTTP 状态、SHA-256、响应头与批次。解析文件和字段映射均可重建，不覆盖原件。
- SQLite 请求账本记录 run、每次请求的 started/finished/blocked 状态、预算消耗、耗时、Retry-After 和错误；同站一把进程锁覆盖探测/列表/详情网络步骤。请求在发出前占预算，异常退出留下 started，恢复前必须离线 reconcile。
- 龙岩来源行 ID 为 `longyan-2026-white-nonsubject:<工作表>:<Excel行号>`，同名的不同来源行不合并。候选对象仅为官方名单行，不是已核许可证或登记主体。办学许可、登记主体、校区名称、课程和联系方式若无原字段均为 JSON null。
- 完整收据需要原件存在、哈希一致、XLSX 身份/表头通过、所有实际数据行可定位、数量可复算；下一次运行只有通过离线收据核验才可跳过。失败原件单独标 `quarantine`，不得默默重抓；人工判定后用新批次追加观察。
- CLI：`inspect`（纯离线，显示来源与状态）、`fetch-list`（联网，强制 `--max-pages --max-ids --max-requests`，研究用途确认）、`fetch-detail`（此来源无公开详情端点，非零退出且不联网）、`verify`（纯离线检查收据/损坏/待续）、`export-candidates`（纯离线写私有 JSONL，`publishable=false`）。不提供自动发布命令。

## 模块与数据流

独立 `collector/` Python/uv 包，不修改现有 Next.js 页面。`sources/longyan.py` 仅处理已经确认的 XLSX 和字段位置；`network.py` 只负责同站锁内请求、预算与速率、失败阻断；`store.py` 只负责 SQLite 账本和不可覆盖原件；`receipts.py` 离线核验完整性；`export.py` 映射私有候选与逐字段证据；`cli.py` 编排，不承载业务规则。HTTP 使用 httpx，XLSX 使用 openpyxl，互斥用 filelock，测试用 pytest；CSV 若未来确有来源，再用标准库 csv，不预造通用爬虫。

流程：来源政策复核 → 明确硬预算的单次 XLSX GET → 请求开始记账 → 收到响应立刻写不可覆盖原件 → 记录结束状态/响应头/哈希 → 校验 HTTP、XLSX 身份与表头 → 解析并保留原始行/未知列/null/重复观察 → 离线收据验收 → 私有候选导出。原始名单和候选不流向网站公开 API。首批仅处理白名单，字段 `regulatory_listing` 明确不是 `license`。

## 失败、恢复与验证

- 429 记录 Retry-After 并停批；403、验证码、错误文件类型/业务身份不符阻断；网络超时及 502/503/504 仅在显式预算内有限重试，任何尝试都计数。预算用尽停批，不以退出码 0 伪装完成。
- 首批 `min_interval_seconds` 由本来源独立配置为保守的 30 秒操作值（并非站点承诺，也不是养老项目参数）；样本只有一个正式附件请求，不承诺永不触发限流。生产定期调度保持关闭。
- 测试完全用本地字节/模拟传输，不请求真实网站，覆盖空表、重复行、未知列和 null、单文件无分页边界、列表已验收而详情缺失、403/429、文件身份不符、原件损坏、预算耗尽、异常中断与多进程锁。
- 上线前再做来源许可/隐私审查、复核与公开投影；当前研究 CLI 不能被网站代码直接调用。根目录无 Git 仓库，交付时提醒版本控制状态，不擅自改养老工程。
