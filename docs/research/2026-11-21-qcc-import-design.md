# 企查查导出接入与教培详情补充：实施设计

日期：2026-11-21。目标是把用户已有的 25 份企查查高级搜索 XLSX 导出导入本项目的**私有登记主体候选库**，保留可回溯证据，再用单独的官方教培名录寻找机构、校区与许可信息。第一步不把工商主体认定为获许可培训机构；不把候选数据接入现有公开 Next.js 的 Org、搜索、API、sitemap 或演示交易流程。

## 输入、权限和成功标准

- 输入 Source of Truth：`教育/` 中 25 份原始 XLSX（另一个 `~$` 临时文件忽略）。第 1 行是企查查声明，第 2 行为 37 列表头，第 3 行起为数据；部分文件工作表声明维度错误，读取时必须基于实际行扫描。导出包含登记主体信息和联系字段，不含办学许可、校区和课程。
- 原件只读，不移动、重命名或改写。私有导入库放在 Git 忽略的 `collector/var/qcc.sqlite3`；任何派生文件仍在 `collector/var/`。企查查声明禁止向第三方出售及向境外传输/存储/使用；公开展示和再利用许可未确认。先不通过 Next.js 服务公开。
- 验收：25 文件各有 SHA-256、原始行数、导入行数及不可覆盖收据；导入总数与逐文件复算一致，缺失代码、重复观察与非企业类型原样保留。CLI 可离线检查和按名称/代码有限查询，且明确显示“工商登记主体候选”。同名或同业务范围不自动成为机构。

## 数据模型与边界

`qcc_files` 记录文件 ID（文件名+SHA-256 的稳定散列）、相对路径、原件 SHA-256、字节数、表头、导入开始/完成 UTC、行数和状态。`qcc_rows` 用“文件 ID + 工作表 + Excel 行号”作观察 ID，保存全部 37 列的原始 JSON 值、原始字段名、企业名称、统一社会信用代码、登记状态、注册地址等仅供检索的副本。空值为 null；数字/日期的原始单元格类型另按可逆 JSON 表示。名称及代码索引只加速查询，不合并观察。

`RegistrationSubjectCandidate` 是登记主体候选，覆盖公司、个体工商户、独资企业等不同类型；`Institution`、`Campus`、`License`、`Course` 仍由各自来源证据建立。企查查主体与官方名单行只能产生 `pending` 关联候选；即使名称相同，也须人工核对地区、地址、主体和许可，才可确认关系。登记状态只能表示企查查导出时的登记字段，不代表当前办学许可。

离线数据流：原始 XLSX → 校验固定表头和 SHA-256 → 逐文件事务写入 SQLite 原始观察 → 文件收据离线复核 → 有界 CLI 查询 → 官方名录记录的待核匹配。读取、导入和清洗分开；不在 Python 导入时请求网站，也不在 Next 页面或 API 中读取私有库。

## 接口、故障与验证

- `python -m edu_collector.qcc_import inspect`：只读列出文件、行数、缺失和已导入批次；不联网。
- `python -m edu_collector.qcc_import import --max-files N --max-rows N`：只读 XLSX，有限、离线、逐文件原子导入；遇表头、工作表或行预算异常停止该文件并保留可审计错误，不跳到“完成”。同一文件有完整且可复核的收据才跳过。
- `python -m edu_collector.qcc_import search --name/--uscc --limit N`：只查私有候选，分页上限；不把它们作为培训机构输出。
- 中断恢复：单文件事务回滚、下一次复核 SHA 和数据库行数后跳过完整文件，未完成文件重试须留事件；原件变化产生新文件观察而不覆盖旧批次。导入锁防止并行写库；SQLite 错误和预算不足显式失败。
- 测试：不联网，覆盖免责声明/表头位置、假维度、null、未知字段、跨文件重名、缺失代码、损坏文件、预算、中断后恢复、幂等与文件锁。使用真实文件只做最终受限导入验收；验收分别报原始行数、不同代码数、缺失数、导入数和官方逐家核验数。

回滚仅删除本次生成的私有 SQLite/收据（保留用户原始 XLSX）并停止调用新 CLI；现有演示页、公开接口和养老参考工程均不改。后续官方详情来源须先单独核对 robots、条款、公开使用条件和字段，再作来源专属适配器；遇登录、验证码、403/429 停止，不绕过访问控制。

## 第二来源：济南高新区白名单的小样本

候选为[济南高新区 2026-10-30 校外培训机构白名单](https://innovation.jinan.gov.cn/col/col89688/art/2026/art_2bc8258b48a24493b521b44a3cb760fc.html)。实际原件的逐家表格有 121 个编号行，仅含序号、区县、机构名称、地址、办学内容、办学许可证号六列；“高新区教育文体部”是页面发布机构，不是逐行主管部门，发证日期也不在表格内。网页混有成人考研/专升本机构，须逐行标类别待核；不同名称可能共用相同许可编号，应作为异常而非自动合并。robots 地址返回 HTML 首页，未获得明确机器人规则；持续采集及再利用授权未核实。因此仅执行一次低频、硬上限的内部页面取样，不上定时器、不公开发布。原始 HTML 进同一请求账本和私有原件目录；解析保留所有编号行和原字段，“办学内容”仅表示名单刊载的文字，不等于具体课程或对许可证原件核定范围的复核。与企查查主体只生成待核关联，不按名称、地址或许可证号自动认定同一对象。
