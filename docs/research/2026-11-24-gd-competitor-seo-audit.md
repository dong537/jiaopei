## 本轮已落地的路径

- 广东首页保留名称/许可证号检索，并通往有实际记录的地市、来源检索和名单解读。
- 地市页增加该市实际接入公告的标题、发布单位、观察日期与记录数，链接到来源卡；档案能返回地市、原公告、同公告其他记录及名单解读。同公告仅表示同一来源，不表示同一机构。
- 广东面包屑以规范的广东首页为根，档案末级采用原文机构名；页面可见层级与 BreadcrumbList 一致。首页只有一个层级时不输出不足两项的 BreadcrumbList。
- 名单解读页明确四类来源与字段的证据边界，使用可见正文及描述性内链；没有为了 GEO 添加专用文件、FAQPage 或未核实的机构 Schema。
- 无正式投影时继续 noindex、robots 禁抓、sitemap 空；获准发布后 sitemap 才列出首页、来源页、方法页与确有记录的地市。无真实内容变更记录前不伪造 lastmod；筛选/搜索变体 noindex，规范分页使用各自 canonical。

## 正式上线前仍缺

1. **权利与详情质量**：逐来源商用再利用及建链许可、公告撤回机制、单条备注和年检结论复核、发布日期与原件行定位。没有这些，不应公开候选记录或宣称现时许可有效。
   本机浏览器抽样还发现一条年度检查预览记录的 OCR 名称字序混乱；该来源需逐行校正或从发布批次排除，不能让搜索引擎收录错名。
2. **可信运营入口**：真实运营主体、可控制的域名和备案、更正/投诉渠道及响应责任人。不能放假联系方式或把“打开原公告”当作本站更正入口。
3. **发布后 SEO/GEO 验证**：部署环境逐页检查 200/noindex/canonical/robots/sitemap，抽样原公告链接，观察搜索平台索引和 AI 引用数据。当前预览的禁抓状态正确，不能用实验室检查推断自然流量或 AI 引用。

## 本机自测证据

- 离线 Node 测试 24/24 通过；ESLint、TypeScript 和 Next 16.4.6 生产构建通过。构建中新增的广东名单解读页存在，但没有正式发布文件。
- Playwright/Chromium 在 320、375、768、1440px 检查广东首页、来源、解读、地市与档案共 20 个页面视口组合：均返回 200、无横向溢出及浏览器控制台错误；面包屑可见层级与 JSON-LD 对齐。375px 还验证首页→解读→来源→地市，以及档案→来源、分页 canonical 和筛选变体。截图保留在私有的 output/playwright/gd-seo-audit/，该目录被 Git 忽略；这是自测，不是用户验证。
- 无正式投影的生产模式抽检：广东首页、来源与解读页均 noindex，不显示私有预览；sitemap 无 URL，模拟机构 API 为 404、旧演示机构路由重定向。正式域名、发布投影与 Search Console 尚未验证。
- Next 16 的流式未知城市/档案可能返回 200 加 noindex 的 404 内容，发布后须观察 soft-404 并考虑更早的不存在判断。生产构建仍编译旧原型路由，部署必须由 Next proxy 拦截，后续应从正式构建中移除原型。

Google 的[AI 搜索功能指南](https://developers.google.com/search/docs/appearance/ai-features)没有要求专用 GEO 标记；[可抓取链接指南](https://developers.google.com/search/docs/crawling-indexing/links-crawlable)强调真实链接和明确锚文本；[分页指南](https://developers.google.com/search/docs/specialty/ecommerce/pagination-and-incremental-page-loading)建议分页使用各自规范 URL。本站按可核实资料与用户任务实现这些基础，不承诺排名。
