# 全国地区×机构类别调研矩阵与逐来源填表模板（2026-11-22）

> 配套 `2026-11-22-object-model-and-national-plan.md`。本文件是**可操作模板**：
> 调研时每发现一个具体来源，就在第 2 节按模板填一行；每核验一个县区，就在第 1 节矩阵里更新状态。
> 未调查地区保持「未知」，不填 0。所有结论附 URL、页面位置、访问日期。

## 1. 全国地区 × 机构类别调研任务矩阵

### 1.1 状态定义

| 状态 | 含义 |
|---|---|
| `未调查` | 尚未开展任何来源检索 |
| `已找到` | 找到候选来源，但未打开核对 |
| `已核验` | 实际打开原件、核对至少一条样本、填齐第 2 节字段 |
| `受阻` | 需登录/验证码/403/429/附件失效/扫描件/条款不明 |
| `无适用来源` | 检索后确认该地区该类别无公开名单（须注明检索时间与关键词） |

### 1.2 类别代码

- **A** = 教育部门中小学生校外培训白名单/证照齐全/审批公告/年检/停办公告
- **B** = 体育、文化、科技等主管部门名单
- **C** = 人社部门职业技能培训机构名录
- **D** = 教育部门继续教育校外教学点
- **E** = 民政社会组织登记 / 企业信用公示 / 商业目录（仅作补充证据）

## 2. 逐来源填表模板（每份可核验名单/附件填一行）

```text
来源编号：<SRC-省区县-类别-序号，如 SRC-4409-A-01>
行政区划代码：<6位县区码，不设区地级市填4位+乡镇>
层级：省 / 地级 / 县区
机构类别：A / B / C / D / E
页面标题：<原文>
准确原件URL：<附件给附件URL，非列表页>
发布单位：<原文>
发布日期：<YYYY-MM-DD>
名单截至日期：<YYYY-MM-DD 或 未标注>
网页/附件格式：html / xlsx / xls / csv / pdf_text / pdf_scan / image
逐家字段：<机构名:有|无；许可证号:有|无；信用代码:有|无；地址:有|无；办学内容:有|无；年检结论:有|无；有效期:有|无；…>
样本行定位：<表名/工作表:第N行，样本值：机构名=… 许可证号=…>
可见行数：<N 行，仅行数，不混称许可证数/机构数>
更新方式：公告 / 年检 / 动态名单 / 不明
是否登录：是 / 否
robots.txt结论：允许 / 禁止 / 404 / 未声明（附核查URL与日期）
网站条款结论：可下载 / 禁止转载 / 未声明（附条款URL与日期）
是否可网页查询：能 / 不能 / 需登录 / 仅列表
是否技术上可批量取得：是 / 否（依据：附件直链 / 分页 / 接口）
是否允许再利用：允许 / 禁止 / 未声明 / 需授权（附条款原文或URL）
预计解析难度：低 / 中 / 高 / 需OCR
核验时间：<YYYY-MM-DD HH:MM Asia/Shanghai>
证据链接：<已打开核对的页面/附件URL>

四个独立结论：
  1. 公众能否查询单家机构：<能/不能/需登录/仅列表>
  2. 是否有可解析公开原件：<有(格式)/无/扫描件>
  3. 是否允许按拟定频率自动获取及再利用：<允许/禁止/未声明/需授权>
  4. 是否具备稳定原始行ID、发布日期、更新线索：<有/无/部分，说明>

来源分类：首批试点可采集 / 仅能人工查询 / 需授权 / 技术受阻 / 证据不足
备注（限制与下一步）：<遇403/429/验证码即停止，记录真实HTTP状态/重定向/Retry-After>
```

## 3. 行政区划代码参考（截至 2025 年末，民政部国家地名信息库）

- 权威发布页：`https://dmfw.mca.gov.cn/XzqhVersionPublish.html`
- 版本：截至 2025 年末，省/地/县/乡四级；依据《行政区划代码管理办法》（民政部令第 79 号，2025-09-01 施行）。
- 编码规则（节选）：
  - 县级 6 位 = 省 2 + 地 2 + 县 2；直辖市辖区中间两位 01、直辖县 02；省直辖县级中间两位 90。
  - 地级市代管的县级市 81–99 号段；县/自治县 21–50；市辖区 01–20、51–80。
  - 乡级 9 位，街道 001–099、镇 100–199、乡 200–399。
- 使用纪律：调研中任何行政区调整（撤县设区、区划变动）须回到该库核对最新版，并记录版本日期。
