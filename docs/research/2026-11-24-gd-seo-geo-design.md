# 广东信源页面 SEO/GEO 与内链方案

日期：2026-11-24。范围仅为现有广东公开路径的内容、链接、面包屑和索引配置；不新增机构事实、不采集数据、不改变来源发布审批，不承诺搜索收录或 AI 引用。

## 用户与成功标准

用户要按地区或名称找到某条官方来源记录，理解这条记录能证明什么，并回到原公告核对。路径为：广东首页 → 地市/检索结果 → 记录档案 → 原公告；各节点均能返回地市、来源与解释页。首屏保留检索；内容增加字段解读和来源类型区别，不能用重复通用文案铺满城市页。

验收：可见面包屑首级为规范的 /gd；结构化 BreadcrumbList 与可见层级一致；新说明页和记录/城市/来源页之间有可抓取的链接；预览继续 noindex、robots 禁抓、sitemap 空；正式投影存在时 sitemap 只列实际可用的规范页面。320/375/768/1440px、键盘、搜索到档案和返回路径经浏览器自测。

## Source of Truth 与边界

- 机构名称、地址、许可号、培训项目、公告出处来自已审批的广东投影；开发预览来自私有预览文件。单条记录是历史刊载观察，不代表当前许可有效、独立校区或当前招生课程。
- 解释页只定义本站展示口径、核对步骤和信息缺口；不把企查查候选、商业平台资料、旧原型价格/评价搬入正式页面。发布日期缺失继续显示未知，不用构建日期替代。
- 现有 getPublicProjection 是唯一读取入口；新页面仅在它返回正式投影时可索引。旧版原型路由与 API 继续由 proxy 关闭。

## 页面与模块

1. PageHero/Breadcrumbs 接受可选根节点。广东路径以“广东名录”/gd 为根，首页不重复“首页 > 广东”，城市与档案沿 /gd → 地市 → 记录展开；旧原型仍保留自身默认面包屑。
2. 新增 /gd/methodology，回答“名单与许可证号、年检、校区、课程分别如何理解”，并引导至来源检索与城市目录。不新增 FAQPage、评分、机构资质 Schema。
3. 首页增加核对方法入口；来源卡可回到对应地市；地市页给出来源和方法入口；档案页有同公告其他记录及方法入口。关联只按相同来源 key，不暗示同一主体或推荐关系。
4. robots/metadata/sitemap 保持发布闸门：私有预览禁索引；正式 sitemap 只增加说明页及有记录地市。记录页是否进 sitemap 等到逐页内容和版权复核后决定，不以总行数生成批量 SEO 页面。
