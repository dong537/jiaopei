# 广东教培信源公开试点：发布边界与数据流

日期：2026-11-23。目标是给查询校外培训机构的访客提供可追溯的广东官方名单观察；不是全省机构总库、实时持证证明或报名交易平台。成功标准：页面只展示通过投影检查的官方名单字段，能逐条回到原公告，明确名单日期、缺失项与覆盖范围；演示价格、评分、订单和企查查私有导出不可由公开入口访问。

## Source of Truth 与对象

- 原件、解析和收据：data/whitelist/ 与 data/whitelist.db，由 scripts/whitelist 管线维护，不是网站公开目录。
- 工商主体候选：collector/var/qcc.sqlite3、data/gd.db，仅私有研究；名称匹配只能生成待核关联，不进入公开机构事实。
- 公开候选：从 wl_rows 生成的最小字段投影。每条是“某部门在某日期的一条名单观察”，不是唯一机构、校区、当前有效许可证或在营状态。不同来源同名、同号异名和来源冲突不自动合并。
- 公开发布许可：来源级权利审查和字段审查由运营负责人记录。未审查通过的来源可在本地预览，但正式运行时关闭。不能把 robots 未声明当作再利用授权。
- 培训类别：只按来源原文展示；职业技能培训、继续教育教学点不混入校外培训白名单口径。年度检查公示单独标记，不能当作现时有效的白名单。

## 模块与流程

1. 官方网站原件 → 现有白名单采集、解析、离线收据和冲突检查 → 私有 SQLite。
2. scripts/build-gd-public.mjs 只读私有白名单库，排除待复核、属地异常、同号异名，保留原文空值并输出私有预览 JSON 与统计收据。正式发布构建必须先取得每个来源的再利用审查证据；不读取企查查库。
3. src/lib/gd/public.ts 只读投影，统一提供首页统计、分页检索、来源列表和单条档案；查询参数有长度、页码和枚举边界。
4. src/app/gd/ 下的首页、城市检索、档案、来源说明只调用该接口。展示“官方名单曾刊载”，附原文 URL、发布日期和采集时间；不宣称实时许可有效、人工核验、收费或质量。
5. 全站公开入口、SEO 与 API 默认只放行广东试点的真实页面。原型功能仅供隔离开发，不对客户发布。若投影文件缺失，显示明确不可用状态，不自动回退到私有工商数据或假数据。

## 界面任务与边界

访客从广东首页看到有记录的地市与来源口径；在城市页按名单原文名称/县区检索；在档案页查看原文机构名、许可号、地址或培训项目（确有原文时）、发布单位与来源链接；在来源页核对接入范围和时间。字段缺失显示“原文未载明”。名单日期不是许可证有效期；无记录也不代表无证。

保留现有蓝色系与基础排版，改用“证据条目”作为视觉重点。首屏呈现查询与覆盖边界，不用大而无依据的全省机构数。详情以原文事实、来源和缺口分组，移动端单列、桌面双列；链接能键盘操作。

## 失败、上线与回滚

- 原库缺失/损坏、解析冲突、来源授权缺失：构建失败或页面明确关闭；不回退到 data/gd.db。发布前检查来源 URL、原件哈希、异常名单、字段抽样及数据日期。
- 公告撤回或冲突：保留私有原件和历史版本；公开投影移除或标注历史，不以旧值覆盖新观察。
- 年检结论、白名单单条备注尚未入库；预览页面须显著提醒回查原文，正式发布前逐来源复核这些影响资质理解的字段。
- 公开批次发布采用可回滚的投影文件与收据；部署必须含已审查投影、生产路由 smoke check、来源链接抽样与数据删除/更正通道。
- 本轮验收：离线测试覆盖去重、异常排除、空字段和发布闸门；npm run lint、类型检查、npm run build；浏览器或 HTTP 检查首页、城市、详情、来源、空态、移动视口以及演示路由和 API 不暴露。

## 当前阻断

现有来源的商业再利用条款与五个深圳来源的访问限制尚需逐来源复核；企查查导出第三方公开再利用未获确认。正式对外发布、真实客户访问、备案/域名、法定主体标注、监控和运营更新责任必须完成发布验收后才能声称可正式运营。本轮只交付可审查的真实数据预览和受控发布路径。
